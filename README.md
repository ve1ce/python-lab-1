# Лабораторная работа №1 — Введение в Python

## Описание

В рамках лабораторной работы были выполнены 11 практических заданий по основам языка программирования Python.

В заданиях были рассмотрены и применены:

* переменные и базовые типы данных;
* арифметические операции;
* условные выражения;
* списки и кортежи;
* словари и множества;
* индексация и срезы строк;
* циклы `for`;
* функции;
* импорт и использование модулей;
* автоматическое тестирование с помощью `pytest`.

Проект выполнен с использованием модульной структуры: логика каждого задания находится в отдельном Python-модуле, а файл `main.py` используется для запуска всех заданий.

## Выполненные задания

### Задание 00 — Расстояния между городами

Реализовано вычисление расстояний между городами по заданным координатам.

Результат сохраняется в виде вложенного словаря, содержащего расстояния между каждой парой городов.

### Задание 01 — Работа с кругом

Рассчитана площадь круга с заданным радиусом.

Также определено, находятся ли заданные точки внутри круга.

### Задание 02 — Арифметические операции

Составлено выражение с использованием заданных чисел и арифметических операций, результат которого равен `25`.

### Задание 03 — Любимые фильмы

С помощью индексации и срезов строки получены:

* первый фильм;
* последний фильм;
* второй фильм;
* второй фильм с конца.

### Задание 04 — Моя семья

Созданы списки членов семьи и их приблизительного роста.

Рассчитаны:

* рост отца;
* общий рост членов семьи.

### Задание 05 — Зоопарк

Выполнены операции со списком животных:

* добавлен медведь;
* добавлены птицы;
* удалён слон;
* определены номера клеток льва и жаворонка.

### Задание 06 — Список песен

Рассчитано суммарное время звучания выбранных песен группы Depeche Mode.

Для работы использовались список и словарь.

### Задание 07 — Секретное сообщение

С помощью индексации и срезов строк расшифровано зашифрованное сообщение.

Результат:

```text
в бане веник дороже денег
```

### Задание 08 — Цветы

Созданы множества цветов, произрастающих в саду и на лугу.

С помощью операций над множествами определены:

* все виды цветов;
* общие цветы;
* цветы, растущие только в саду;
* цветы, растущие только на лугу.

### Задание 09 — Магазины и цены

Создан словарь с минимальными ценами на продукты в магазинах.

Для каждого продукта указаны два магазина с минимальной стоимостью.

### Задание 10 — Товары на складе

Рассчитаны:

* общее количество каждого товара;
* общая стоимость каждой группы товаров на складе.

## Модульная структура

Для выполнения задания среднего уровня логика каждого задания была помещена в отдельную функцию.

Например:

```python
def calculate_result():
    result = 1 + 2 * (3 + 4 + 5)
    return result
```

После этого функции импортируются в `main.py`.

Файл `main.py` является точкой входа в программу и последовательно запускает все 11 заданий.

Для предотвращения автоматического запуска кода при импорте используется конструкция:

```python
if __name__ == '__main__':
```

## Тестирование

Для выполнения задания повышенной сложности были написаны автоматические тесты с использованием библиотеки `pytest`.

Тесты находятся в директории:

```text
pytests/
```

Для запуска всех тестов используется команда:

```bash
pytest
```

Все 11 заданий покрыты автоматическими тестами.
